# 语音热词与 Agent 技能配置

状态：已完成源码实现与离线测试。真实本人私聊仍需在安装新二进制并重启运行实例后验收。实现约束和测试范围见[详细稿](hotword-agent-skills-design-detail.md)。

## 使用效果

- 正式记忆可以保存标准名称、常见语音转写或别称和简短含义。AI 每轮会收到当前工作区优先、获准全局词其次的精简热词表，默认最多 4,000 字符。
- 本人明确说出标准名和错误叫法时，私聊 Agent 可以把纠正按 Source → Candidate → Review → Apply 保存。AI 自己的猜测只用于当前回答，不能写成正式热词。
- 原始私聊正文保持不变。热词只帮助理解名称，不能授予执行、工具或披露权限。群 Agent 只能看到已向该群发布的热词。
- 同一叫法可以保留多个正式对象，由 AI 结合当前上下文判断；实际操作的目标仍不明确时再向用户询问。
- 本人私聊 Agent 默认继承当前执行器的全局技能。Claude CLI 从 `~/.claude/skills` 发现技能；其他 Agent 默认不继承，只加载配置中声明的路径。

## 配置方式

```yaml
agents:
  owner:
    skills:
      inherit: executor

  project-helper:
    skills:
      inherit: none
      paths:
        - /path/to/project-skill
        - ./skills/issue-helper
```

每条路径是一个含 `SKILL.md` 的技能目录。相对路径按 YAML 文件目录解析，也支持 `~`。显式路径覆盖同名的继承技能；两个显式路径同名会拒绝配置。`memgov-memory` 由运行时管理，不能用配置覆盖。

技能加载不会开启 Bash、网络或外部操作权限。技能清单、说明摘要和内容摘要值会进入应用配置。继承的全局技能在下一轮重新发现并重建持续会话；显式技能内容变化会拒绝旧配置，重新执行配置计划和应用后再建立会话。
