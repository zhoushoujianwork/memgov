# 查看任务的实时执行过程

状态：已在源码实现；需要更新并重启服务。本次完成离线模型与浏览器验收，尚未更新真实安装或运行钉钉任务。实现与验证见[详细稿](task-terminal-detail.md)。

## 使用

Web「任务」页选择运行中的任务，详情自动展开 **Web Terminal**，查看 Claude 的文字输出、工具调用参数、工具结果及可用的 CLI 诊断。过程随事件实时更新，不必等待整个任务结束。

可以暂停自动跟随以阅读前面的内容，随后点击「跟随最新输出」回到末尾。任务有多次执行时，用顶部下拉框切换尝试；已结束任务也可以点「查看 Web Terminal」回看保留的过程。

终端为只读查看窗口。关闭或收起它不影响任务运行。最终成果看「处理结果」，是否送达看「交付状态」；某个工具成功不代表整个任务已经完成。

## 范围

- 支持本人私聊、群 Agent 和主动值守任务的 Claude 执行调用，按公开消息与工具事件更新，不展示隐藏推理。
- 更新服务后的新调用才开始采集。已经运行的旧调用、被清理或到期的日志无法回补；任务继续的每次新尝试单独展示。
- 原请求修改、撤回、到期或私聊清空后，不再展示关联的执行过程。常见凭据与链接脱敏；过程日志是临时运行资料，不写入长期记忆。
- 单次尝试最多保存 4 MiB，页面只保留最近一段内容。达到过程日志上限不会停止 AI 执行。

已有 Schema 21 的安装不需要额外迁移。本次源码更新仍需重新编译并重启服务；从旧版本升级的步骤见[任务继续说明](task-continuation.md)。重启会中断当前调用，可随后按需继续失败任务。
