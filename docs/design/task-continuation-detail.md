# 任务继续的实现与验证

范围和用户使用方式以[主文档](task-continuation.md)为准。

## 状态与入口

Schema 21 为 `runtime_tasks` 增加 `resume` JSON，为 `runtime_attempts` 增加 `agent_session` JSON；Schema 26 为 `runtime_direct_sessions` 增加私聊原生会话 ID、策略摘要和已接受历史摘要，不修改已发布迁移。任务继续记录新任务版本、原尝试 ID、固定“继续”提示与 native/replay 模式；尝试记录原生会话 UUID、策略与上下文摘要、工作分支与基准提交，以及受控目录工作状态。SQLite 仍负责任务、恢复关系、版本和审计，Claude 原生会话文件仅保存可恢复的执行上下文。

`runtime task resume <task-id>` 与统一服务注入的 Web 控制回调均调用 `ResumeRuntimeTask`。Web 为 `POST /api/v1/tasks/<task-id>/resume`，要求当前 `expected_version`、本机 loopback 访问边界、同源 JSON 和 `X-Memgov-Console: 1`。请求在写事务中检查失败状态、原尝试版本、原文保留及当前路由/Agent 声明、私聊本人身份与 clear 屏障，并拒绝外部动作或投递处于 executing/sending/unknown 等不能盲目重试的状态。

继续请求将同一任务置为 pending、增加版本，作废旧待执行动作和旧可发送结果，恢复所属运行模块的 running 控制状态。原尝试、原请求和原工作目录保留；新尝试由原有领取机制串行执行。重复请求、旧页面版本以及 running/completed 等任务被拒绝。`task retry` 清除继续关系，维持从头准备的既有行为；修改原任务增加版本后，旧继续关系不再有效。

Cyber owner 的主动沟通动作跨尝试保留；`sending` 或 `unknown` 会阻止继续和重试。恢复输入包含既有 `communications`，相同业务沟通沿用原幂等键，不能换键重发已受理或结果未知的消息。后台恢复、完成及失败不会创建自动通知；需要继续的阻塞任务可显式 retry，权限和来源仍重新检查。

## Agent 调用与目录

Claude 执行前持久记录确定的会话 UUID。私聊按逻辑会话绑定原生 UUID，二者分开保存；同一钉钉私聊在进程或服务重启后，只要策略摘要和已接受历史摘要一致，继续使用 `--resume <uuid>`。摘要不一致、原生会话不可用或历史被撤回/修改时，不沿用旧原生上下文，改用已接受轮次回放并创建新的原生 UUID。每轮记录实际使用的原生 UUID；显式失败任务继续仍沿用原有 `--resume`/replay 规则。

执行调用启用 Claude 本地会话保存；分析、记忆复核和单独确认动作仍沿用无会话保存模式。原生继续沿用相同 UUID 和原目录，发送“继续”以及检查已有成果、核对外部操作状态的固定提示；旧任务 replay 使用新 UUID，额外提供原请求并明确未保存中间上下文。恢复策略、能力、记忆共享范围/类别排除、声明目录、技能和通道提示的摘要必须匹配；原文、已接受会话、记忆上下文和目录快照摘要变化也会拒绝原生上下文复用。继续不授予新执行或披露权限。

代码任务沿用原 worktree、分支和基准提交，保留未提交进度。旧普通 worktree 从其创建分支的 reflog 恢复基准；基准无法确认或分支变化则拒绝继续。受控目录使用原准备状态及写入边界；旧版本缺少此状态时要求重新准备。完成仍执行原验证和本地提交要求。工作目录丢失、原生会话文件缺失或调用报错时按失败处理，不宣称成功，不盲目启动第二次模型调用。

## 验证

检查覆盖启动恢复后原尝试及会话 ID 保留、旧任务 replay、同一任务新增版本、重复/旧版本拒绝、撤回与路由退出、未知外部结果拒绝、CLI 与 Web 继续请求及所属模块恢复。真实本地假 Claude 子进程测试在初次调用写入部分进度后取消，再创建新运行时进程实例，核对 `--resume` 和“继续”指令、原文件与最终结果；该测试不调用真实模型或钉钉平台。

原生上下文匹配检查覆盖能力、会话历史和目录范围变化；工作区检查覆盖旧 worktree 未提交进度与原基准的恢复；HTTP 检查覆盖会话、同源、请求头、期望版本及只读查询连接保留。交付说明另行报告全仓库检查、浏览器点按、安装及真实平台验收结果。
最终验证：隔离本次改动的工作区执行 `make check`（vet 与全仓库测试）通过；`go test -race ./internal/core ./internal/runtime ./internal/console ./internal/cli -run 'Resume|Continuation' -count=1` 通过。离线浏览器实际点按「继续任务」后，任务变为待处理，原失败尝试保留，按钮移除，页面显示所属模块已恢复、等待 Agent 接手。浏览器测试仅运行本地控制台，不启动模型或平台工作进程；未更新真实安装、升级真实数据库或执行钉钉平台任务。
