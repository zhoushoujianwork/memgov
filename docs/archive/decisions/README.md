# 旧版设计存档

本目录内 0001—0004 及 SQL 文件描述旧版设计，保留用于理解历史数据。它们不约束 memgov v2，也不是新版安装或操作指令。

每份文件顶部都标注历史状态；正文中的结论、命令、代码路径、计数和测试结果只表示当时情况。不要据此创建原子文件、调用旧命令，或将权威数据库作为可删除的派生索引。

新版权威设计见 [architecture.md](../../architecture/architecture.md)。新版不采用旧三轴、原子/卡片/战斗模型、Markdown 真相源或 Skill 运行框架。
